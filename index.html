03 / МЕТОДИКА

Баллы, которые можно объяснить

Прозрачная модель для демонстрации. Коэффициенты и качество источников должны быть проверены с партнёрами до реального запуска.

ФОРМУЛА ДЕМОИндекс = min(100, Σ баллов подтверждённых достижений)

Баллы достижения = вес уровня × коэффициент результата. Непроверенные записи дают 0 баллов. Здесь нет «Elo» и национального перцентиля без данных реальной выборки.

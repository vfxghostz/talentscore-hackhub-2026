# TalentScore — Lean Canvas

| Блок | Гипотеза |
|---|---|
| Проблема | Фонды и вузы вручную сравнивают несопоставимые достижения школьников. Региональные кандидаты теряются в отборе. |
| Покупатель | Региональный фонд поддержки талантов; затем приёмная комиссия вуза. Плательщик — организация, не школьник. |
| Пользователь | Школьник 8–11 класса из региона Казахстана, имеющий результаты в олимпиадах, хакатонах или инженерных конкурсах. |
| Ценность | Покупатель получает объяснимую подборку подтверждённых кандидатов; школьник видит оценку достижений и путь развития до появления покупателей. |
| Решение | Протокол организатора → подтверждение школьником и законным представителем → индекс по направлению → обезличенный поиск → согласованное знакомство. |
| Каналы | Пилот с одним организатором областной олимпиады или хакатона в Актобе; приглашение по списку результатов. Прямые интервью и продажа фондам и вузам. |
| Доход | Гипотеза: 150 000 ₸/месяц за пилот с подборкой и согласованными знакомствами. Цена требует проверки. |
| Затраты | Сопоставление протоколов, ручная верификация спорных записей, поддержка пользователей, хранение и защита данных, продажи. |
| Ключевые метрики | Доля приглашённых, активировавших профиль; число подтверждённых достижений; доля согласий; число релевантных подборок; конверсия в согласованное знакомство; платный пилот. |
| Альтернативы | Ручная проверка грамот, таблицы организаторов, школьные рекомендации, профильные олимпиады и хакатоны. |
| Главное допущение | Один подтверждённый источник может быстро привести первых школьников, а объяснимый поиск даст покупателю достаточно ценности для пилота. Пока не проверено. |

**Ограничение:** модель не заявляет национальный перцентиль и не сравнивает между направлениями до калибровки на реальных данных.
